## Lot « fonctionnalités »
1. **Bouton « Regarder »** sur un match en direct → stream (`getLive` : `streams[]` avec `provider` twitch / youtube / afreecatv, `parameter`, `locale`) ; préférer le stream `fr-FR`, sinon `en-US`, sinon le premier. Match terminé : **« Revoir »** game par game (`getEventDetails` : `games[].vods[]` YouTube, `parameter`, `locale`, `startMillis` / `endMillis`).
2. **Notifications locales de début de match** (« KC vs C9 dans 15 min ») programmées à l'avance depuis le calendrier en cache, réglables ; jamais pour un prochain match que `Presenter.nextLine` cache (règles F1 / C), jamais de résultat.
3. **Draft et builds (avec icônes)** — demandé par Dan : « des icônes et images pour les spells, les items, les champions ».
   - Champions : `window` → `gameMetadata.*.participantMetadata[].championId` ; image Data Dragon `https://ddragon.leagueoflegends.com/cdn/<version>/img/champion/<championId>.png` (version : `api/versions.json`, la plus récente qui commence par le patch du flux `gameMetadata.patchVersion`, ex. « 16.18 »).
   - Objets : `livestats/v1/details/{gameId}?startingTime=` → `participants[].items` (ids) → `cdn/<version>/img/item/<id>.png` (noms : `data/fr_FR/item.json`).
   - Runes : `participants[].perkMetadata` (`styleId`, `subStyleId`, `perks`) → icônes de `data/fr_FR/runesReforged.json`.
   - Sorts du champion (A/Z/E/R) et ordre de montée : `participants[].abilities` (ex. E, W, Q, Q, Q, R…) + `data/fr_FR/champion/<id>.json` → `spells[].image`.
   - **Sorts d'invocateur (Flash, Téléport…) : absents du flux de Riot** (vérifié le 14/10 sur `window` et `details`) → pas affichables.
   - Bonus disponibles : part des dégâts (`championDamageShare`), participation aux kills, balises posées / détruites, niveau, CS.
   - Cache disque des images (comme les logos), pas de téléchargement pour un match masqué.
4. **Fil des événements de la game** (kills, drakes avec leur type, barons, tours, inhibs) calculé par différence entre frames successives ; horodaté au temps de jeu.
5. **Courbe de l'écart de gold** pendant la game (frames lues toutes les 10 s) et pour une game terminée (le flux sert les games passées : relecture à pas de 60 s, à la demande).
